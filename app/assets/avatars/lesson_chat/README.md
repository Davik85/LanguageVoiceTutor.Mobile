# Lesson Chat avatars

Tutor folders are `lana/`, `nelli/`, and `david/`. Each tutor uses
`avatar-idle.gif` and `avatar-speaking.gif`. Idle, listening, thinking, and
transcribing use the idle GIF; speaking uses the speaking GIF. These are compact
lesson-chat assets. A missing asset falls back to the same tutor's idle GIF,
then to a neutral placeholder.
